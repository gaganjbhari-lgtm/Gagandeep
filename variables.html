Variables in C

Variables are named places in memory where a program stores data. Their type tells C what kind of value they hold.

Learn the basics Back to Home 
int age = 18;
double height = 1.72;
char grade = 'A';
01 | BASICS

Declare and initialize

Declare a variable by writing its type and name. You can assign it a starting value at the same time.

int score;        /* declaration */
score = 100;      /* assignment */

int lives = 3;    /* declaration + initialization */
02 | TYPES

Common data types

Choose a type that matches the kind of data you need to store.

int count = 12;          /* whole number */
float temperature = 21.5f; /* decimal number */
double price = 19.99;    /* more precision */
char initial = 'G';      /* one character */
03 | RULES

Naming variables

Names can contain letters, digits, and underscores. They cannot start with a digit, contain spaces, or be C keywords. Names are case-sensitive.

int student_age;  /* valid */
int score2;       /* valid */
int 2score;       /* invalid: starts with a digit */
04 | EXAMPLE

Use variables in a program

This example reads two whole numbers, adds them, and prints the result.

#include <stdio.h>
#include <conio.h>

void main()
{
    int first_number;
    int second_number;
    int sum;

    printf("Enter two numbers: ");
    if (scanf("%d %d", &first_number, &second_number) != 2) {
        printf("Invalid input.\n");
        return 1;
    }

    sum = first_number + second_number;
    printf("Sum: %d\n", sum);

    return 0;
}
